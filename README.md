# 소리소문 생존 - 아이패드 웹앱

리움 키즈랩 〈일상 속 사라짐〉 전시용 아이패드 앱입니다.
HTML / CSS / JavaScript 파일만으로 되어 있어서 빌드 과정 없이 그대로 배포합니다.

```
IDLE(기본 모드) ─ '영상 보기' 탭 ─▶ TITLE(소제목 페이드 인, 약 2.8초) ─▶ VIDEO(영상+사운드)
   ▲                                                                          │
   └──── 6초간 조작 없으면 자동 복귀 ◀── END('처음으로' 버튼) ◀── 영상 종료 ────┘
```

## 1. 폴더 구조

```
02_APP/
├─ index.html              설치 안내 화면 (3종 주소 목록 - 관람객용 아님)
├─ a/index.html            02 전용 화면  ←┐
├─ b/index.html            03 전용 화면   │ 아이패드마다 하나씩
├─ c/index.html            01 전용 화면  ←┘
├─ app.css                 디자인 (Figma 1180x820 좌표 그대로)
├─ app.js                  화면 생성 + 동작 (3종 공통)
├─ config.js   ★           문구·타이밍·영상 경로 - 여기만 고치면 됩니다
├─ sw.js                   서비스워커 (아래 용어 설명 참고)
├─ _headers                Cloudflare Pages 캐시 설정
└─ assets/
   ├─ video/    A.mp4 / B.mp4 / C.mp4      ← 완성 영상을 여기에
   ├─ poster/   A.png / B.png / C.png      영상 로딩 전 보여줄 첫 화면
   ├─ fonts/    GabiaGosran.woff2          가비아 고스란체
   └─ icons/    icon-192.png / icon-512.png
```

★ 표시된 `config.js` 하나만 열면 자막 문구, 페이드 시간, 영상 파일 이름을 다 바꿀 수 있습니다.

`a` / `b` / `c` 폴더의 `index.html` 은 "이 주소는 몇 번인지"만 지정하는 몇 줄짜리 파일입니다.
화면과 동작은 `app.js` 한 곳에 있으므로, 고칠 일이 생겨도 한 파일만 고치면 3종에 모두 반영됩니다.

## 2. 용어 정리 (처음 보는 단어들)

| 단어 | 뜻 |
|---|---|
| **PWA** | Progressive Web App. 웹사이트를 아이패드 홈 화면에 아이콘으로 저장하면 사파리 주소창 없이 앱처럼 전체 화면으로 뜨는 방식입니다. 별도 앱 심사나 설치 파일이 없습니다. |
| **서비스워커 (Service Worker)** | 브라우저 안에 상주하는 작은 프로그램. 앱 파일을 기기에 저장(캐시)해 둬서 두 번째 접속부터 훨씬 빠르고, 와이파이가 잠깐 끊겨도 화면이 유지됩니다. `sw.js` 파일이 그 역할을 합니다. |
| **Cloudflare Pages** | 파일을 올려두면 주소(URL)를 주는 무료 호스팅 서비스. GitHub 저장소와 연결해 두면 코드를 푸시할 때마다 자동으로 다시 배포됩니다. |
| **캐시 (Cache)** | 한 번 받은 파일을 기기에 저장해 두는 것. 빨라지지만, 수정한 내용이 바로 안 보일 수 있어 `_headers` 파일에서 조절합니다. |
| **사용자 유도 모드 (Guided Access)** | iPadOS 기본 기능. 앱 하나에 화면을 잠가서 관람객이 다른 앱으로 못 빠져나가게 합니다. 전시장 필수 설정입니다. |

> **서비스워커와 Cloudflare Pages는 둘 중 하나를 고르는 것이 아닙니다.**
> Cloudflare Pages = 앱을 올려두는 **주소(서버)**,
> 서비스워커 = 아이패드 안에서 파일을 **저장해두는 장치**.
> 이 프로젝트는 둘 다 씁니다.

## 3. 영상 넣기

`assets/video/` 폴더에 아래 이름으로 넣습니다.

| 파일 | 내용 |
|---|---|
| `A.mp4` | 02 · 풀벌레 소리 대신 들리는 사라짐의 소리 |
| `B.mp4` | 03 · 짝을 부르는 소리에 다가오는 건 사냥꾼 |
| `C.mp4` | 01 · 차 소리에 묻히는 새소리 |

### 파일 하나당 25MB 미만으로 맞춰 주세요

Cloudflare Pages는 파일 하나가 **25MiB**를 넘으면 배포를 거부합니다.
30초 영상이므로 평균 **5~6Mbps**로 맞추면 약 20MB가 됩니다.
검정 배경 + 흰 선화 소재라 압축이 잘 먹어서 실제로는 더 작게 나옵니다.

권장 내보내기 설정

- 코덱: **H.264 (High)** + AAC 오디오 — 사파리에서 확실히 재생됩니다
- 해상도: **2360 x 1640** (아이패드 화면의 2배)
- 프레임: 30fps / 비트레이트 평균 5~6Mbps, 최대 8Mbps
- 오디오: AAC 128~160kbps
- **Fast Start(웹 최적화) 켜기** — 없으면 재생 시작이 몇 초씩 늦어집니다

터미널이면:

```bash
ffmpeg -i 원본.mov -c:v libx264 -profile:v high -pix_fmt yuv420p \
       -crf 22 -maxrate 8M -bufsize 16M \
       -c:a aac -b:a 128k -movflags +faststart A.mp4
ls -lh A.mp4   # 25MB 아래인지 확인
```

25MB를 못 맞추면 Cloudflare R2(같은 계정의 파일 저장소, 무료 10GB)에 영상만 올리고
`config.js`의 `video` 값을 R2 주소로 바꾸면 됩니다.

영상 파일이 아직 없으면 앱은 포스터 이미지와 함께 "영상 파일이 없습니다" 안내를 띄우고
자동으로 IDLE로 돌아갑니다. 지금 상태 그대로 배포해도 동작합니다.

## 4. 폰트 넣기

디자인 폰트는 **가비아 고스란체**입니다.
`assets/fonts/GabiaGosran.woff2` 로 넣어 주세요. (눈누 또는 가비아 폰트 페이지에서 받을 수 있습니다)

`.ttf` 만 있다면 웹용으로 변환:

```bash
pip install fonttools brotli
fonttools ttLib.woff2 compress GabiaGosran.ttf
```

폰트가 없어도 애플 산돌고딕으로 대체되어 화면은 정상 동작합니다.

## 5. A / B / C 주소

한 번 배포하면 주소가 세 개 생깁니다. 아이패드마다 자기 주소를 열어 홈 화면에 추가합니다.

```
https://주소/c/     01  차 소리에 묻히는 새소리
https://주소/a/     02  풀벌레 소리 대신 들리는 사라짐의 소리
https://주소/b/     03  짝을 부르는 소리에 다가오는 건 사냥꾼
```

주소마다 아이콘 이름이 `소리소문 01` / `02` / `03` 으로 따로 붙어서,
홈 화면에서 어느 기기가 몇 번인지 바로 보입니다.
회차 순서와 주소 글자(a/b/c)는 서로 다릅니다 - 위 표를 보고 맞춰 주세요.

`https://주소/` 로 열면 세 주소를 고르는 설치 안내 화면이 나옵니다.
설치할 때만 쓰고, 관람객에게는 보이지 않습니다.

## 6. 아이패드 세팅 (전시 시작 전 체크리스트)

1. **설정 > 디스플레이 및 밝기 > 자동 잠금 → 안 함**
2. **설정 > 손쉬운 사용 > 사용자 유도 모드 → 켬**, 암호 설정
3. 사파리로 앱 주소 접속 → **공유 버튼 > 홈 화면에 추가** → 홈 화면 아이콘으로 실행
4. 화면 한 번 넘겨서 영상까지 재생되는지 확인 (첫 실행 때 파일을 받아 저장합니다)
5. **소리 확인** — 제어 센터에서 무음 모드 해제, 볼륨 최대
6. 홈 화면 아이콘으로 앱 실행 후 **홈 버튼(또는 상단 버튼) 3번 눌러 사용자 유도 모드 시작**
7. 기기를 **비행기 모드로 두지 마세요** — 와이파이 연결 상태에서 운영합니다

> 소리가 안 날 때 가장 흔한 원인은 **무음 스위치 / 제어 센터 무음**입니다.
> 앱 코드로는 우회할 수 없으니 기기 설정에서 꼭 확인해 주세요.

## 7. 수정하고 다시 올리기

1. `config.js` 나 다른 파일을 수정
2. `배포하기.command` 더블클릭
3. 아이패드에서 앱을 완전히 종료 후 다시 실행

배포할 때마다 서비스워커 버전이 배포 시각으로 자동으로 바뀝니다.
아이패드가 예전에 저장해 둔 파일을 버리고 새로 받게 하는 장치이며,
직접 손댈 일은 없습니다.
